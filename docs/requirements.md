## 2. 서비스 개요

### 2.1 서비스 목적

업무 문서를 업로드하면 AI Agent가 내용을 구조화해 분석하고, 핵심 주장·사실·결정사항을 근거와 함께 요약한다. 사용자가 긴 문서를 읽는 시간과 핵심 정보 탐색 비용을 줄이는 것이 목적이다.

### 2.2 대상 사용자

- 보고서·회의록·계약서·기획서를 검토하는 직장인
- 연구자료의 핵심을 파악하려는 학생·연구자
- 여러 문서의 이슈와 결론을 확인하는 관리자 또는 일반인

### 2.3 해결하려는 문제

- 회의록·보고서·계약서처럼 수십 페이지에 이르는 문서를 검토할 때, 사용자는 결론·결정사항·담당자 같은 핵심 정보를 찾기 위해 문서 전체를 읽어야 한다.
- 문서마다 제목 체계와 표현 방식이 달라, 같은 목적의 정보라도 사용자가 직접 검색하고 비교해야 하므로 검토 시간이 길어진다.
- 기존 AI 요약은 각 문장이 원문의 어느 부분에 근거하는지 확인하기 어렵고, 원문에 없는 내용이 섞이면 사용자가 결과를 다시 대조해야 해 신뢰하기 어렵다.

### 2.4 핵심 가치

업로드부터 결과 확인까지의 흐름을 단순화하고, 요약과 근거를 함께 제공해 결과를 빠르게 검토하고 신뢰할 수 있게 한다.

## 3. 요구사항 정의의 전제와 가정

- 1차 MVP는 로그인 없는 단일 사용자 흐름으로 구성한다.
- PDF와 TXT를 우선 지원하며 DOCX·이미지·스캔 문서는 후속 범위로 둔다.
- AI 모델과 API 제공자는 비용, 한국어 성능, 개인정보 처리 조건을 비교해 선정한다.
- 문서는 필요한 기간만 보관하고, 구체적인 기간은 운영 정책에서 확정한다.
- AI 결과는 참고용이며 법률·의료·재무 판단을 대신하지 않는다는 안내를 제공한다.

## 4. 서비스 범위

### 4.1 MVP 포함 범위

문서 업로드, 형식·용량 검증, PDF/TXT 텍스트 추출, AI 분석, 구조화된 요약 결과 표시, 오류 안내, 결과 복사 및 Markdown/TXT 다운로드를 제공한다.

### 4.2 MVP 제외 범위

다중 사용자·권한 관리, 공동 편집, 외부 저장소 연동, OCR, 다중 문서 비교, 모델 학습·개인화, 전문 분야의 자동 판단은 제외한다.

## 5. 사용자 흐름

사용자가 파일을 선택하거나 끌어 놓으면 시스템은 형식과 크기를 검증하고 텍스트를 추출한다. 이후 AI Agent가 문서 유형과 내용을 분석하고, 요약·핵심 내용·키워드·후속 조치를 표시한다. 사용자는 결과를 복사하거나 다운로드한다.
